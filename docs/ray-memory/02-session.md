# 세션 관리

---

## 1. 세션 정의

- wakeword로 시작, 종료 명령어 또는 일정 시간 무입력으로 종료
- 길이는 가변적 — 한두 마디부터 긴 대화까지

---

## 2. LLM 인풋 블록 구성

```
┌─────────────────────────────────────┐
│ 1. System Prompt (정적)             │  레이 성격, 지침
├─────────────────────────────────────┤
│ 2. User Context (반정적)            │  유저 프로필 (매 턴 전체 로드)
├─────────────────────────────────────┤
│ 3. Conversation History (동적)      │  이전 세션 요약/원문 + 현재 세션 대화
├─────────────────────────────────────┤
│ 4. Retrieved Memories (상시검색)    │  에피소드 기억 (Retained + 신규)
└─────────────────────────────────────┘
```

- 블록 1~3은 같은 유저 턴 내 사전생성들 간 동일 → Prefix Caching으로 KV 캐시 재사용 가능
- 블록 4는 맨 뒤에 배치하여 캐시 히트율 극대화

---

## 3. 블록 3: Conversation History

### 이전 세션

최근 N개 세션을 타임스탬프 + 세션 구분자로 감싸서 포함한다.

- 일반 세션: 요약 텍스트
- 짧은 세션 (기준 턴 수 이하): 요약 없이 원문 그대로 (원문이 요약보다 짧으므로 LLM 호출 불필요)
- 요약 미완료 시: 원문 또는 요약 없이 진행

```
[2026-03-28 14:00 세션]
(요약) 사용자가 주말에 듄을 다시 봤다는 이야기를 했고, ...

[2026-03-28 21:30 세션]
사용자: 지금 몇 시야?
레이: 9시 반이야.
```

- 이 세션들의 내용은 메모리에 아직 write되지 않은 상태
- 히스토리에서 밀려나는 시점에 메모리 Write 처리 (04-write.md §1)

### 현재 세션

현재 대화 턴들을 그대로 포함.

토큰 초과 시:
- 슬라이딩 윈도우 (오래된 턴 제거)
- 필요 시 앞부분 요약 방식 추가 검토

---

## 4. 세션 시작 시 처리

- 프로필 로드 (블록 2)
- 이전 세션 요약/원문 로드 (블록 3)
- Retained Buffer 리셋 — 세션 간 대화 맥락이 끊기므로 이전 세션의 retained 상태를 유지하지 않음

---

## 5. 세션 종료 시 처리

1. 세션 요약 생성 (비동기 LLM 호출, 짧은 세션은 생략)
2. 기억 인용 데이터 반영 — 세션 중 인용된 기억의 recency_decay 기준 일시 DB 갱신
3. 히스토리에서 밀려나는 세션이 있으면 메모리 Write 트리거
