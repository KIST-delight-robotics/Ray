# 시스템 특성

> 대상 시스템: 레이(Ray) — 실시간 음성대화 챗봇
> 구동 환경: 라즈베리파이 5, 우분투
> 기본 언어: 영어

---

## 레이의 컨셉

- 비서/어시스턴트가 아닌 **친구** 컨셉
- 영화, 책, 음악 등을 잘 알고 설명하기 좋아하는 친구 (구현 방향은 미정)
- 장기기억의 목적: 사용자와의 대화에 사용하기 위함. 친구다운 기억이 중요 — 구체적 에피소드("비 오는 날 인터스텔라 보면서 울었다며")가 건조한 속성("SF를 좋아함")보다 대화적 가치가 높음

## 사전 호출 (Turn Shift) 구조

- 별도 턴테이킹 모듈이 사용자 발화 종료를 예측
- 종료 판정 전, "끝난 것 같은" 시점마다 STT 텍스트로 LLM 생성 시작
- 사용자가 계속 말하면 이전 생성 취소, 새 사전생성 실행
- 턴 종료 판정 시 마지막 생성 결과를 사용
- 각 사전생성의 STT 텍스트는 서로 상당히 다를 수 있음 (검색 결과 재사용 어려움)

## 세션

- wakeword로 시작, 종료 명령어로 끝나는 한 번의 대화 단위
- 세션 길이는 가변적
