# 모터 캘리브레이션 — 동작 방식

RAY의 머리는 와이어 세 줄(pitch, roll_r, roll_l)로 움직인다. C++ 프로세스(`build/Ray`)는 기동할 때마다
이 세 줄을 다시 맞추는 캘리브레이션을 돌린다. 이 문서는 그 과정이 **무엇을 보고, 어떻게 움직이고, 언제
멈추는지**를 설명한다. 설정 절차는 `docs/SETUP.md`, 결정 배경은 `docs/decisions-wip.md`에 있다.

## 1. 목표

캘리브레이션이 끝났을 때 머리는 두 조건을 만족해야 한다.

1. **수평** — 앞뒤, 좌우 모두.
2. **세 줄이 모두 팽팽하다** — 어느 모터를 당겨도 머리가 바로 따라 움직인다.

2번이 중요한 이유: 줄이 헐거우면 모터가 감기 시작해도 슬랙이 걷힐 때까지 머리가 안 움직인다.
모션이 늦게 시작되고, 축마다 지연이 달라 자세가 틀어진다.

저장된 위치로 그냥 이동하는 방식은 쓰지 않는다. 와이어는 쓸수록 늘어나고, 전원이 꺼져 토크가 풀리면
머리 무게에 스풀이 되감겨 수백 틱씩 풀리기 때문에, 어제의 "홈 위치"가 오늘은 맞지 않는다.

## 2. 전제 지식

**감기 방향.** 모터 위치를 줄이면(−) 줄을 감아 당기고, 늘리면(+) 푼다.

**세 줄이 머리를 받치는 방향.** roll_r·roll_l은 머리 뒤쪽 좌우에서 당기고, pitch는 앞에서 당긴다.
그래서 roll 둘을 같이 당기면 머리가 뒤로 젖혀지고, pitch를 당기면 앞으로 숙여진다.
roll_r과 roll_l은 좌우로 반대 방향, roll 둘과 pitch는 앞뒤로 반대 방향이다. **반대 방향의 두 줄이 동시에
당기고 있으면 둘 다 팽팽하다** — 이게 이 캘리브레이션의 기본 도구다.

**센서.** 머리에 붙은 가속도 센서(MPU6050)가 중력 방향을 읽는다. 머리가 수평이면 Ax ≈ 0, Ay ≈ 0.
좌우로 기울면 Ax, 앞뒤로 기울면 Ay가 움직인다. 단위는 g, 0.05 g ≈ 2.9°.
센서가 머리에 조금 비뚤게 붙어 있거나 칩 자체의 영점 오차가 있으면 수평일 때도 0이 아닌 값이 나오는데,
그 값을 `calib_ax_offset`으로 빼 준다 (기기별).

**토크가 풀리면 어떻게 되나.** 머리가 앞으로 처지면서 roll 줄은 스풀이 되감겨 헐거워지고(roll_r은
400틱 가까이), pitch 줄은 머리가 다가오니 그냥 늘어진다. 즉 기동 시점엔 대개 세 줄이 다 헐겁다.

## 3. 핵심 원리

### "팽팽하다"의 판정 = 감았을 때 머리가 움직였다

줄이 헐거우면 아무리 감아도 센서 값이 그대로다. 감았는데 머리가 기울기 시작했다면 그 순간부터 줄이
팽팽한 것이다. 캘리브레이션은 이 사실 하나로 텐션을 판단한다 — 장력 센서가 없어도 된다.

노이즈 때문에 "조금 움직였다"는 믿을 수 없으니, **수평을 지나 0.05 g(≈2.9°)만큼 확실히 기울 때까지**
감는다. 이 값이 `calib_tension_g`다.

### 한쪽을 더 당긴 뒤 반대편으로 수평을 맞추면 양쪽이 팽팽해진다

한쪽 줄을 수평 너머 0.05까지 당긴다. 그다음 반대 방향 줄을 당겨 머리를 수평으로 돌려놓는다.
먼저 당긴 줄은 그 길이에 고정된 채 머리가 반대로 끌려갔으니 당겨진 상태로 남고, 나중에 당긴 줄은
지금 당기고 있으니 당연히 팽팽하다. 결과적으로 두 줄이 서로를 당기는 상태가 된다.

이때 수평으로 돌려놓은 각도(0.05 g)만큼 줄이 필요 이상으로 조여진 채 남는데, 이걸 **당김량**이라 부른다.
크면 머리가 과하게 조여지고, 작으면 노이즈에 속아 헐거운 줄을 팽팽하다고 착각한다. 그래서 문턱은
"노이즈를 확실히 넘는 최소값"으로 잡는다.

## 4. 단계

```
① yaw 정렬  →  ② 이완  →  ③ roll  →  ④ pitch  →  ⑤ mouth
```

### ① yaw 정렬

yaw는 수평 회전이라 중력 센서로 기준을 잡을 수 없다. config의 `default_yaw`(정면을 보는 틱 값)로
그냥 이동한다. **기기마다 다른 값이니 `RAY_UNIT`이 맞는지 확인할 것** — 다른 기기 값이 들어가면
머리가 크게 돌아간다.

### ② 이완 — 세 줄을 일단 헐겁게

roll_r → roll_l → pitch 순서로, 한 모터씩 60틱 풀고 센서가 변했는지 본다. 변했으면(아직 팽팽했으면)
그 모터를 더 풀고, 안 변했으면 다음 모터로. 세 모터 모두 안 변할 때까지 반복한다.

왜 굳이 풀고 시작하나: 뒤의 단계들은 감기만 한다. 이완이 없으면 캘리브레이션을 반복할수록 조여지기만
한다. 왜 하나씩인가: 셋을 한꺼번에 풀면 세 줄이 서로 균형 잡힌 채 팽팽한 경우 머리가 안 움직여 놓칠 수
있다.

mouth(턱)는 센서로 감지할 수 없어 고정량(250틱)만 푼다.

### ③ roll — 좌우 수평 + roll 두 줄 텐션

Ax 부호를 보고 낮은 쪽부터 당긴다. 예를 들어 머리가 오른쪽으로 처져 있으면(Ax < 0):

```
roll_r 당김:  Ax가 +0.05를 넘을 때까지      ← 수평을 지나 왼쪽으로 2.9° 오버슈트
roll_l 당김:  Ax가 −0.01 아래로 올 때까지    ← 수평 복귀. roll_r은 당겨진 채 남음
```

끝나면 두 roll이 모두 팽팽하고 좌우가 수평이다.

### ④ pitch — 앞뒤 수평 + pitch 텐션

```
(머리가 앞으로 처져 있으면) roll 둘을 함께 당겨 Ay ≤ 0.009까지   ← 수평 선행
pitch 당김:  Ay가 0.059(= 수평 0.009 + 0.05)를 넘을 때까지        ← 앞으로 2.9° 오버슈트
roll 둘 당김:  Ay ≤ 0.009까지                                    ← 수평 복귀. pitch는 당겨진 채 남음
```

목표를 "지금 위치에서 +0.05"가 아니라 **"수평에서 +0.05"** 로 잡는 점이 중요하다. 당김량은
되돌아온 양으로 정해지므로, 시작 위치 기준이면 머리가 처진 만큼 당김량이 커진다.

Ay 추이를 그리면 이렇다.

```
Ay
0.06 ┤              ╭─╮
     │             ╱   ╲
     │            ╱     ╲
0.01 ┤───────────╯       ╲──────   ← 수평
     │  수평 선행  pitch   roll 둘
     │  (roll 둘)  감기    되당김
     └────────────────────────────▶ 시간
```

### ⑤ mouth

턱은 센서가 없어 모터 전류로 본다. 3틱씩 감으면서 전류가 급변하는 지점(줄이 팽팽해져 부하가 걸리는
순간)을 찾고, 거기서 60틱 되돌린다.

## 5. 어떻게 움직이고 읽나

**연속 이동.** 모터에는 "goal까지 50 ms에 도착"하는 프로파일을 주고, 정확히 50 ms마다 다음 goal을 준다.
그러면 모터는 멈추지 않고 이어서 움직인다. goal을 더 자주 주면 모터가 따라오지 못해 실제 위치가 goal보다
뒤처지고, 문턱을 넘은 걸 늦게 알아 목표를 지나친다. 반대로 매 스텝 멈추고 읽으면 정확하지만 덜덜거린다.

**두 가지 감기.**
- *빨리 감기* (roll만): 줄이 헐거운 동안 10틱씩 빠르게. 센서가 움직이기 시작하면 끝.
- *정밀 감기*: 6틱씩, 문턱에 닿을 때까지. roll 둘을 함께 당길 땐 머리가 두 배 빨리 움직이니 3틱씩.

pitch에는 빨리 감기가 없다. 목표까지 거리가 0.05밖에 안 돼 빠른 판정의 오차를 감당할 수 없고,
구조상 pitch 슬랙은 원래 적기 때문이다.

**읽기.** 감기 단계는 스텝마다 3샘플(30 ms)을 이동 끝자락에 겹쳐 읽는다. 이완 단계는 이동이 끝나고
잔진동이 가라앉은 뒤 10샘플을 읽는다 — 이완은 "변화가 없다"를 판정해야 해서 노이즈에 더 민감하다.
센서에는 저역통과 필터(DLPF 21 Hz)를 켜 두어 노이즈를 기본값의 1/3로 줄였다.

## 6. 설정값

`cpp/config.toml`. 공용 `[robot]` 항목과 기기별 `[robot.unitN]` 항목이 있다.

| 항목 | 값 | 뜻 |
|---|---|---|
| `calib_tension_g` | 0.05 | 텐션 판정 문턱 = 오버슈트 각도 = 당김량. 좌우로 밀어 유격이 느껴지면 올린다 |
| `calib_release_step_tick` | 60 | 이완 1스텝 풀기 양 |
| `calib_release_noise_g` | 0.03 | 이완 "변화 없음" 판정 임계 |
| `calib_release_mouth_tick` | 250 | mouth 고정 이완량 |
| `calib_mouth_backoff_tick` | 60 | mouth 장력점에서 되돌리는 양 |
| `profile_velocity_calib` | 50 | 감기 스텝의 프로파일 시간(ms) = 스텝 주기 |
| `default_yaw` (기기별) | — | 정면을 보는 yaw 틱. 유일하게 실제 사용되는 홈 값 |
| `calib_ax_offset` (기기별) | — | 육안 수평일 때의 Ax. 좌우 수평의 기준점 |

`default_pitch/roll_r/roll_l/mouth`는 참고 기록용이고 캘리브레이션이 매번 새로 정한다.

## 7. 로그 읽기

```
[RELEASE] roll_r → 1174 (변화 없음, Δ 0.014)          ← 첫 스텝에 Δ < 0.03, 이미 헐거웠음
[RELEASE] pitch  → 3630 (이완 진행, Δ 0.036 0.031 0.044 0.016)   ← 세 스텝 동안 팽팽, 네 번째에 풀림
[CALIB] roll_r 빨리 감기 34스텝(340틱) → 정밀 감기      ← 슬랙 340틱
[CALIB] roll 단계 3875 ms
[CALIB] pitch 시작 Ay=0.072 → 목표 Ay>=0.059            ← 머리가 앞으로 처진 채 시작 → 수평 선행 있음
[CALIB] pitch 단계 5081 ms
default_pitch = 3415  default_roll_r = 664  default_roll_l = 2658   ← 이번 홈
```

정상 범위(mk3 실측):
- 당김량(pitch 피크 Ay − 되당긴 뒤 Ay): 0.05~0.065
- roll 오버슈트 종료 Ax: 0.05~0.06
- 같은 조건 반복 시 결과 위치 차이: ±20틱
- 전체 시간: 22~28 s. 산포는 거의 시작 슬랙(직전에 어떻게 꺼졌나)에서 온다

## 8. 한계

- **읽기 산포.** 토크가 걸린 상태에선 모터가 미세하게 떨어 한 번 읽은 값이 ±0.02 g(≈1°) 흔들린다.
  최종 수평도 그 정도 안에서 실행마다 다르다.
- **Ay 오프셋 없음.** 앞뒤 수평은 센서 영점을 그대로 믿는다. 기기에 따라 보정 항이 필요할 수 있다.
- **기계적 스토퍼.** 머리가 스토퍼에 걸려 못 움직이면 "변화 없음"으로 읽혀 팽팽한 줄을 헐겁다고 본다.
- **mouth 단계는 검토하지 않았다.** 원 구현 그대로이고 ~8 s가 걸린다.
